How this was selected

Activity is more than a raw commit count.

The base scan covered 24 local Git checkouts, 79 GitHub repositories visible to the authenticated account, and 21 publicly enumerable repositories on the self-hosted Gitea. Targeted follow-ups added explicitly supplied private histories plus read-only audits of T:\p4\UE5\.looman and the Factory archive on 9800x3d. The order is editorial rather than a raw score: direct evidence of multi-agent planning, long-horizon execution, verification, tool use, multimodal generation, and physical-system control comes first, followed by substantial product and enabling-infrastructure work. Imported fork history was not treated as original activity: cmux has 5,434 reachable commits but no locally authored commits found, so it is omitted.

Metric notes

Two line metrics, kept deliberately separate.

  • Dates are earliest and latest commit dates unless explicitly labeled “activity” or “run”; “span” is elapsed calendar days.
  • Commit counts use each primary main history. Authoritative remotes replace stale workstation refs; the grouped wmux card combines its web and mobile histories. Factory has no root Git history and is excluded.
  • The per-card text lines and top summary are scale proxies, not lines of code. They count tracked UTF-8 source, tests, docs, configuration, and research/results where those artifacts are part of the product, while excluding locks, builds, dependencies, and binaries.
  • The chart is a separate committed source metric from Git numstat. Its programming-language whitelist excludes JSON, JSONL, Markdown, MDX, YAML, TOML, XML, TXT, CSV, locks, data/result/generated paths, dependencies, vendor code, and binaries. Tests count; rewrites count again; deletions are reported separately, so it is churn rather than current SLOC.
  • Complexity labels combine size with integration surface; infrastructure can be complex with relatively little code. Public enumeration was supplemented by targeted SSH reads of the private repositories the user supplied.
